

concat(x, y) ≡ x + y (mod M)
x * f(y) + y ≡ x + y (mod M)
※ f(y)はyの最大桁数倍

yは払えるので
x * f(y) ≡ x (mod M)

xを移行して
x{ f(y) - 1} ≡ 0 (mod M)

f(y)は10~10e19なのでループ可能

係数をaとすると
ax ≡ 0 (mod M)
x : 1~Nの間

という問題になる

a:2, M:4
x: 2, 4, 6, 8, 10...
となり2の倍数になる

g = gcd(a, M)と置くと条件が
x ≡ 0 (mod M/g) となる

N以下の xの個数は

N / (M/g)
